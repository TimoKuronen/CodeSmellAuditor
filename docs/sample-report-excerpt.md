# Sample Report Format

This excerpt shows the report structure generated by CodeSmellAuditor.

## File naming

```
{TargetFileNameWithoutExtension}_{yyyyMMdd_HHmmss}_Critique.md
```

Example: `SampleService_20260707_120000_Critique.md`

## Front matter

```yaml
---
TargetFile: SampleService.cs
AuditDate: 2026-07-07 12:00:00
Tags: [code-smell-audit]
---
```

## Body (compact format)

```markdown
# Audit Report: SampleService.cs

Status: REVIEW REQUIRED
Score: 72

## Top Findings
- Constructor takes 8 dependencies; consider grouping related configs
- Direct Unity type usage in domain logic reduces testability
- No null checks on injected dependencies at wiring boundary

## Missing Context
- Composition root registration not visible in this file

## Recommended Next Step
Extract spawn planning into a dedicated planner class and inject it as a single dependency.
```

## Interrupted reports

If the model exceeds its output budget, the report may be truncated.
